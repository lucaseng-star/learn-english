UI Kit 设计规范

从 ui-replica.html 抽出的设计语言，与布局解耦。任何新后台复用这一层，布局各写各的。

三个文件：assets/ui-kit.css（变量 + 组件）、assets/ui-icons.svg（32 个图标）、本页（规范与样例）。

图标未加载：本页需通过 http 打开。本地运行 npx serve 后访问，或直接看 assets/ui-icons.svg。

颜色

共 4 组。新增颜色前先确认现有的哪一个不够用——大多数情况下够用。

字号阶

移植到其他技术栈

变量层是纯 CSS 自定义属性，任何框架都能直接用。下表是常见栈的对应关系。

目标栈怎么接
原生 HTML/CSS直接 <link> 引 assets/ui-kit.css，容器加 class="uk"。
Tailwind把 :root 里的值填进 theme.extend（colors / borderRadius / boxShadow / fontSize），组件类不用移植，用工具类重组。
React / Vue引入 ui-kit.css 当全局样式，组件只负责结构与状态；aria-selected / aria-current 驱动选中态，不要另造 .active 类。
图标同源下 <use href="assets/ui-icons.svg#i-bot"/>；跨域或打包场景把需要的 <symbol> 直接内联。

不可协商的约束

违反任何一条，"看起来是一套"就会当场失效。

  1. 颜色只从变量取。出现第 5 个绿色，说明是漏了变量，不是需要新颜色。
  2. 字号只用 6 级。需要"介于 14 和 18 之间"，先问为什么，而不是加一级。
  3. 图标只用这 32 个的描边风格。混进实心图标库（Material、FontAwesome）立刻破功。
  4. 选中态永远是 --uk-brand-soft 底色，不是左边框、不是加粗。
  5. 状态用 ARIA 属性表达（aria-selected / aria-current），不另造类名——样式和可访问性同一套真相。
  6. 深色导航栏只放一级导航。二级永远进列表栏或工具栏。
